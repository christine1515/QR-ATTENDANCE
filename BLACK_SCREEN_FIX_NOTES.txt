BEFORE BUILDING
1. Keep your existing .env file private. Do not upload it publicly.
2. In Expo dashboard, open the project matching this app's EAS project ID.
3. Add these variables to the Preview environment:
   EXPO_PUBLIC_SUPABASE_URL
   EXPO_PUBLIC_SUPABASE_ANON_KEY
   Use the values from your own .env file. Never use a service-role key in the app.
4. Run `npm ci`.
5. Run `npm run typecheck`.
6. Run `npx expo-doctor`.
7. Build the APK: `npx eas-cli build --platform android --profile preview`
8. Download the APK from the EAS build page and test login, navigation, camera permission, QR scan, and attendance.

If build succeeds but app is still black:
- Connect the phone with USB debugging and collect logs using `adb logcat`.
- Check that both EAS environment variables are defined for the selected build environment.
- Do not paste any secret keys into public chats or repositories.

BACKEND REQUIREMENTS
